# Pintia 题库转复习 Markdown

把用户提供的 Pintia 题库 JSON 整理成便于阅读和复习的 Markdown 文件。此 skill 仅在对话中已提供、上传或明确指定了可读取的题库 JSON 时适用；没有题库 JSON 时先请用户提供，不要仅凭 Pintia 页面描述或答案 JSON 编造题目。用户另外提供的「我的答案」JSON 是可选输入。

## 工作步骤

1. **确认输入**
   - 读取题库 JSON，检查顶层 `questions` 数组及其中题目对象；常见顶层信息包括 `title`、`problemSetId`、`source`、`summaries` 和 `exportedAt`。
   - 若另有答案 JSON，检查其 `answers` 数组。题库和答案都有非空 `problemSetId` 时必须一致；不一致则暂停合并并告知用户。
   - 题目可能包含 `id`、`number`、`type`、`title`、`prompt`、`content`、`options`、`images`、`apiData`、`problemConfig` 等字段。详见[题库导出契约](../../../docs/question-export-contract.md)。
2. **整理题目**
   - 保留原题目顺序和题号；除非用户要求按主题重排，否则不要臆造章节或知识点。
   - 题干优先使用 `content`，缺失时再使用 `prompt`；不要把不同字段不加判断地拼接。只有在字段内容完全相同、确定是重复副本时才去重；内容不同但含义相似时保留必要信息，不能擅自删题意。
   - `options` 是单独的选项来源。若题干中已完整包含同一组选项，避免再次重复列出；仅在选项文本及顺序明确一致时合并，否则保留结构化选项并注明题目字段可能重复或不完整。
   - 内部可使用题型和题目 ID 识别、匹配题目，但成品只显示题号，不显示题型或题目 ID。保留题干中可读的图片链接；无法读取的图片或缺失字段不补造，也不添加缺失字段提示。
   - 可以规范 Markdown 空行、标题、列表和代码围栏，但不要改写代码、公式、选项含义或填空顺序。对无法确定的题干、选项、填空位置或字段冲突，保留原始信息并做简短提示。
3. **处理可选答案 JSON**
   - 默认只整理题目；即使用户附带答案 JSON，也不要将作答、标准答案、解析或正确性信息加入复习题库，除非用户明确要求包含答案。
   - 用户明确要求在复习题库中包含答案时，优先按题目 `id` 与答案项 `problemId` 精确匹配；若题目没有可匹配 ID，仅当题号和题型都存在且组合唯一时才可匹配。无法唯一匹配的答案不要猜测或加入。
   - 答案 JSON 中的 `answer` 默认表示用户提交/提供的作答，不代表标准答案。加入复习题库时明确标注为「我的答案」；除非答案项带有明确可信的正确性标记，或用户明确标注、告知哪些答案正确，否则不得显示为标准答案或判定为正确。
   - 若用户另行要求解答，将 AI 推理答案与题目内容分开标注为「AI 参考答案 / 待核对」，不可伪装成题库或平台提供的答案。
4. **输出 Markdown**
   - 按[复习题库 Markdown 模板](./templates/review-bank.template.md)组织结构；模板中的占位符和示例说明必须替换为实际内容，不要原样作为最终成果输出。
   - 题库 JSON 与答案 JSON 仅在用户明确要求创建或整理这些 JSON 文件时才输出。分别参考[题库 JSON 模板](./templates/question-bank.template.json)和[答案 JSON 模板](./templates/answer-json.template.json)，并遵守[答案 JSON 契约](../../../docs/answer-json-contract.md)；模板占位值不是可直接用于回填的答案。
   - 使用题库标题作为一级标题；标题下仅保留可用的题集链接（优先使用 `source` 字段）。不添加题目总数、题集 ID、来源说明、答案说明或导出提示。
   - 按原顺序整理题目。每题呈现题干和选项；仅在用户明确要求包含答案时，额外显示已唯一匹配的「我的答案」。保留原题号作为简洁题目标题，不显示题目 ID 或题型。填空题保留原有空格和填空顺序，不补答案或额外说明。
   - 每个选项必须使用独立的 Markdown 列表项（例如 `- A. 选项内容`），确保渲染后每个选项单独占一行；不要用普通连续文本或仅靠源文件换行分隔选项。
   - `content` 与 `prompt` 仍按题干规则择一使用。若题干内已完整包含与 `options` 文本及顺序一致的选项，不要重复列出；若不一致则保留题干与结构化选项，不擅自删改。
   - 保留题干所需的可读图片链接、代码和公式；没有可用图片时不添加图片占位章节。缺失的题干或选项不编造。
   - 默认不添加答案/正确性栏目、免责声明、整理说明、字段质量汇总或其他复习无关信息。仅在用户明确要求包含答案时，才在对应题目选项后以「我的答案：…」显示匹配到的作答；不显示正确性判断。若字段冲突会导致题意不清，只在对应题目处用一句短注说明，并保留相关原文。
   - 用户指定了输出位置时写入该位置。未指定时，若源文件路径可用，将文件保存到源文件旁，文件名使用 `<题库标题>-复习题库.md`；不得覆盖已有文件，必要时添加序号。若没有可写入的源文件位置，则在回复中提供完整 Markdown。
   - 回复中简要说明输出位置；不要把答案核实或数据质量清单写进复习 Markdown。

## 不可违反的约束

- 题库 JSON 是必需输入；答案 JSON 可选。不要从外部页面、网络或隐藏数据补充题目或答案。
- 附带模板仅用于展示成果物结构；除非用户要求创建 JSON，否则不要把模板当成需要重写的输入文件，也不要把占位内容作为真实题目、ID 或答案。
- 不得把最近提交内容、平台评测状态或本模型推测自动等同于标准答案。
- 不得为缺失的题干、选项、题号、题目 ID、答案或评测状态编造内容；不确定时保留原始题目内容，必要时只在该题处简短提示。
- 该 skill 整理的是复习资料，不执行 Pintia 页面回填或保存操作。
