# Pintia 学习辅助工具

适用于 Chrome 和 Edge 的浏览器扩展，帮助你在 Pintia 页面识别和导出题目、整理作业回顾，也可以把你提供的答案填入页面。AI 只在你主动点击生成时调用；AI 答案可能出错，使用前请核对。

> **重要：** 点击「AI 生成答案」后，扩展会在答案校验通过时，自动按「回填题型」写入并保存到当前 Pintia 页面。操作前务必确认当前题集和「回填题型」；复核失败、没有选中回填题型或没有匹配答案时不会自动回填。

## 功能一览

- **识别与读取题目：** 在 Pintia 题集概览页和题目页识别当前题集；进入题目页后逐题读取，并显示提取进度。
- **导出题目与作答：** 导出题库 JSON、作业 Markdown 和可用于答题页的「我的答案 JSON」，也可批量处理其他题集。
- **AI 辅助答题：** 使用用户配置的模型服务生成答案；可选答案复核，生成和发送题目数据均由用户主动触发。
- **校验、回填与保存：** 校验答案后按题目 ID 精确定位支持的题型；符合条件的 AI 答案可按「回填题型」自动写入并保存。
- **检查答题进度：** 手动检查活跃题目集已作答比例，并缓存最近结果；100% 只表示均已作答，不代表答案正确，检查不会修改或保存答案。
- **辅助控制与更新提示：** 从扩展弹窗控制助手显示和题集检测，并查看 GitHub Release 更新提示。

## 安装

### 使用 GitHub Release（推荐）

1. 从[最新 Release](https://github.com/quynj/pintia-answer-extension/releases/latest) 下载 ZIP 文件并解压到一个固定文件夹。
2. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
3. 打开「开发者模式」，点击「加载已解压的扩展程序」，选择解压后包含 `manifest.json` 的文件夹。
4. 在 Pintia 页面刷新浏览器标签页，让扩展生效。

扩展不会自动更新本地安装目录。发现新版本后，下载并解压新版，再到扩展管理页重新加载新版文件夹。

### 从源代码构建

需要安装 Node.js 22 或更新版本。在仓库根目录运行：

```bash
npm ci
npm run build
```

然后在扩展管理页加载生成的 `dist/` 文件夹，而不是源码文件夹。

## 快速上手

1. 登录 Pintia，打开题集概览页或具体题目页。助手默认自动显示；若没有显示，可点击浏览器工具栏中的扩展图标，再点「显示或隐藏助手面板」。
2. 助手分为「答题」「导出」「进度」「日志」四个标签页。进入具体题目页后会逐题读取并显示提取进度；加载期间已读取的题目可用于提示词和 AI 生成。详情缓存 10 分钟，刷新页面可复用；如需重新读取，可在扩展弹窗点击「检测题集」强制刷新。「进度」页进入时显示最近一次检查结果，不会自动重新请求；点击「手动检查进度」才会更新。进度结果会在本地缓存，题集间隔默认 1000 毫秒且可调整。确认过期的题目集会在本地记住，后续跳过请求并从进度列表隐藏。100% 只代表题目均已作答，不代表答案正确；检查不会提交、修改或保存答案，过期或接口数据不足时不会误报完成。
3. **导出题目和作答：** 「导出」页会识别并默认勾选当前题目集，可直接导出 Markdown、「我的答案 JSON」或题库 JSON。当前题目集在概览页也可识别；如需批量导出其他题集，可点「加载题目集」后多选。题集间隔由三种导出共用；「Markdown 包含作答内容」只影响 Markdown，答案 JSON 始终包含各题型可关联的最近提交记录及 `problem-status` 接口对应的可选题目状态，可直接用于「答题」页。该状态只供核对平台评测结果，不是标准答案；没有可用提交的题目会略过，导出不会推断标准答案。

   **Markdown 仅供粗略参考：** Pintia 的题干和选项可能分散在多个字段中，导出结果可能有内容缺失或重复，排版也可能不如 Pintia 页面完整。导出的作答是最近提交，不等于标准答案；请对照页面核对。若要整理成复习题库，可安装并使用[题库转复习 Markdown skill](.agents/skills/pintia-review-markdown/SKILL.md)：

   ```bash
   npx skills add quynj/pintia-answer-extension --skill pintia-review-markdown
   ```

   安装后，将导出的题库 JSON 提供给 AI agent，并提出例如「请使用 Pintia 题库转复习 Markdown skill，将这个题库整理成复习题库」。题库 JSON 是必需的；「我的答案 JSON」可选，提供后会按题目 ID 匹配并整理为我的答案。若包含 `problemStatus`，文档会显示平台已判定的正确/错误；待判定、缺失或未知状态不会推断为正确或错误。
4. **使用自己的答案：** 在「答题」页选择「回填题型」，将答案 JSON 粘贴到「答案内容」，检查后点击「校验并回填/输入」。进入编程题编辑器页面后，助手还会显示独立的「当前编程题代码」文本框，可直接粘贴并点击「直接回填代码」。答案 JSON 格式见[答案 JSON 契约](docs/answer-json-contract.md)。
5. **使用 AI：** 点「AI 配置」填写服务商支持的 API 类型、完整接口地址、模型名称和 API Key。API 地址会被直接请求，不会自动补路径：
   - Chat Completions 填完整的 Chat Completions 接口，例如 `https://api.example.com/v1/chat/completions`。
   - Responses API 填完整的 Responses 接口，例如 `https://api.example.com/v1/responses`；只有服务商支持 Responses API 时才选择此类型。
   - 如果服务商文档给的是 Base URL（例如 `https://api.example.com/v1`），请根据所选 API 类型和服务商文档在后面补上接口路径；如果文档给的已经是完整接口地址，就原样填写。保留服务商要求的版本号和自定义路径前缀，不要重复添加路径。

   配置好后返回页面，选择「生成题型」与「回填题型」，点击「AI 生成答案」后，校验通过的答案会自动按「回填题型」写入并保存。首次连接某个 API 地址时，浏览器会询问是否允许连接。

「生成题型」决定哪些题目进入提示词或 AI 请求；「回填题型」单独决定哪些答案会写入页面。两者互不联动。编程题还需要选择生成语言，并在 Pintia 编辑器手动选择相同语言；回填代码会替换编辑器已有全文并保留粘贴内容中的换行。

手动点击「校验并回填/输入」也会回填并保存。一次回填多种题型时，扩展会逐类回填并保存。

## 支持范围

| 题型 | 生成/导出 | 页面回填 |
| --- | --- | --- |
| 单选、多选、判断 | 支持 | 支持 |
| 填空、程序填空 | 支持 | 支持 |
| 编程、SQL 编程 | 支持 | 支持；需在对应编辑器中放置光标并匹配语言 |
| 主观题 | 支持提取与生成 | 暂不支持 |

未列出的题型会保留 Pintia 返回的类型信息，但不支持页面回填。题目内容及字段以平台实际返回为准。

## 隐私与使用边界

- AI 配置和 API Key 保存在当前浏览器的扩展本地存储中。点击生成答案时，所选题目会发送到你配置的模型服务；启用答案复核后还会发送第一阶段答案用于复核。
- 进度检查在扩展本地缓存最近一次检查结果和检查时间，用于打开标签页时快速展示；另用一个列表键持久保存已确认过期的题目集 ID，以避免重复请求。缓存仅包含进度统计，不包含题目内容或答案。
- 扩展不读取隐藏答案、不绕过登录；作业回顾只使用平台返回的提交记录和评测状态，不推断标准答案。
- AI 生成后的自动回填会改变当前页面作答并保存；手动回填也会保存。请先核对题集、答案和回填范围，并确认使用方式符合课程及平台规定。
- 操作结果和错误可在助手的「日志」标签页查看。日志仅保留在当前页面会话中，不记录题目、答案或密钥。

## 问题排查

- **面板未显示：** 在扩展弹窗点「显示或隐藏助手面板」；确认当前标签页是已登录的 Pintia 页面。
- **没有识别到题目：** 打开题集概览页或具体题目页，确认题目已加载，再点「检测题集」或刷新页面。
- **没有看到完整题集列表：** 在助手「导出」页点击「加载题目集」；题库列表不会自动读取。
- **无法生成 AI 答案或收到 HTTP 404：** HTTP 404 表示扩展已发出请求并收到服务端响应，不是本地参数校验失败。检查 API 类型、模型名称和密钥；确认 API 地址是与类型匹配的完整接口 URL，而不只是 Base URL，也没有重复或遗漏路径，并确认浏览器已授予该 API 主机连接权限。页面 DevTools 的 Network 面板不一定显示扩展后台 Service Worker 发出的请求；可从 `chrome://extensions` / `edge://extensions` 打开扩展的 Service Worker 检查器查看 Network。
- **编程题无法输入：** 进入对应题目页，在助手中选择语言，在 Pintia 编辑器选择相同语言，并在操作前将光标放在目标编辑器中。
- **扩展更新后页面仍运行旧版：** 刷新已经打开的 Pintia 页面。
