# Pintia 学习辅助工具

适用于 Chrome 和 Edge 的浏览器扩展，帮助你在 Pintia 页面识别和导出题目、整理作业回顾，也可以把你提供的答案填入页面。AI 只在你主动点击生成时调用；AI 答案可能出错，使用前请核对。

> **重要：** 点击「AI 生成答案」后，「自动回填并保存」默认勾选。保持勾选时，最终答案会自动写入并保存到当前 Pintia 页面。想先检查答案，请在生成期间取消勾选。操作前务必确认当前题集和「回填题型」。

## 安装

### 使用 GitHub Release（推荐）

1. 从[最新 Release](https://github.com/quynj/pintia-answer-extension/releases/latest) 下载 ZIP 文件并解压到一个固定文件夹。
2. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
3. 打开「开发者模式」，点击「加载已解压的扩展程序」，选择解压后包含 `manifest.json` 的文件夹。
4. 在 Pintia 页面刷新浏览器标签页，让扩展生效。

扩展不会自动更新本地安装目录。发现新版本后，下载并解压新版，再到扩展管理页重新加载新版文件夹。

### 从源代码构建

需要安装 Node.js 22 或更新版本。在仓库根目录运行：

```bash
npm ci
npm run build
```

然后在扩展管理页加载生成的 `dist/` 文件夹，而不是源码文件夹。

## 快速上手

1. 登录 Pintia，打开题集概览页或具体题目页。助手默认自动显示；若没有显示，可点击浏览器工具栏中的扩展图标，再点「显示或隐藏助手面板」。
2. 助手分为「答题」「导出」「日志」三个标签页。进入具体题目页后会读取题目并显示进度；如需重新读取，可在扩展弹窗点击「检测题集」。
3. **导出题目：** 在具体题目页的「导出」页选择「导出当前题库 JSON」；导出 Markdown 可从题集概览页或具体题目页点「加载题目集」，选择作业后导出。Markdown 默认包含平台返回的最近作答；取消「包含作答内容」即可不导出。它不是标准答案。
4. **使用自己的答案：** 在「答题」页选择「回填题型」，将答案 JSON 粘贴到「答案内容」，检查后点击「校验并回填/输入」。答案格式见[答案 JSON 契约](docs/answer-json-contract.md)。
5. **使用 AI：** 点「AI 配置」填写兼容 Chat Completions 或 Responses API 的服务地址、模型和 API Key。返回页面后选择「生成题型」并点击「AI 生成答案」。首次连接某个 API 地址时，浏览器会询问是否允许连接。

「生成题型」决定哪些题目进入提示词或 AI 请求；「回填题型」单独决定哪些答案会写入页面。两者互不联动。编程题还需要选择生成语言，并在 Pintia 编辑器手动选择相同语言；编程答案会输入到你操作前放置的光标位置。

手动回填单一题型时，保存选项关闭会只修改当前页面、不提交保存。若一次回填多种题型，为避免切换分类时丢失答案，扩展会先征求确认，确认后逐类保存。

## 支持范围

| 题型 | 生成/导出 | 页面回填 |
| --- | --- | --- |
| 单选、多选、判断 | 支持 | 支持 |
| 填空、程序填空 | 支持 | 支持 |
| 编程、SQL 编程 | 支持 | 支持；需在对应编辑器中放置光标并匹配语言 |
| 主观题 | 支持提取与生成 | 暂不支持 |

未列出的题型会保留 Pintia 返回的类型信息，但不支持页面回填。题目内容及字段以平台实际返回为准。

## 隐私与使用边界

- AI 配置和 API Key 保存在当前浏览器的扩展本地存储中。点击生成答案时，所选题目会发送到你配置的模型服务；启用答案复核后还会发送第一阶段答案用于复核。
- 扩展不读取隐藏答案、不绕过登录；作业回顾只使用平台返回的提交记录和评测状态，不推断标准答案。
- 回填会改变当前页面作答；保存行为受「自动回填并保存」选项影响。请先核对题集、答案和回填范围，并确认使用方式符合课程及平台规定。
- 操作结果和错误可在助手的「日志」标签页查看。日志仅保留在当前页面会话中，不记录题目、答案或密钥。

## 问题排查

- **面板未显示：** 在扩展弹窗点「显示或隐藏助手面板」；确认当前标签页是已登录的 Pintia 页面。
- **没有识别到题目：** 打开题集概览页或具体题目页，确认题目已加载，再点「检测题集」或刷新页面。
- **没有看到完整题集列表：** 在助手「导出」页点击「加载题目集」；题库列表不会自动读取。
- **无法生成 AI 答案：** 检查 API 类型、地址、模型名称和密钥，并确认浏览器已授予该 API 主机连接权限。
- **编程题无法输入：** 进入对应题目页，在助手中选择语言，在 Pintia 编辑器选择相同语言，并在操作前将光标放在目标编辑器中。
- **扩展更新后页面仍运行旧版：** 刷新已经打开的 Pintia 页面。
