# 产品需求规格

## 文档状态与范围

本文是 Pintia 学习辅助工具的用户行为需求基准。扩展面向 Chrome 和 Edge，使用 Manifest V3。代码实现是行为事实来源；用户操作步骤见根目录 [README](../README.md)，技术设计和数据格式见[文档索引](./README.md)。

### 目标

- 帮助用户从已登录的 Pintia 页面读取可访问的题目并导出。
- 让用户检查、生成和按明确范围回填答案。
- 清楚说明数据去向、自动保存行为及平台限制。

### 非目标

- 不读取隐藏答案，不绕过 Pintia 登录、权限或评测机制。
- 不猜测标准答案，不将平台返回的作答或评测状态描述为标准答案。
- 不自动安装扩展更新；不支持主观题页面回填。

## 用户与场景

- **初次使用者：** 下载 Release、在浏览器加载解压目录，并按步骤使用扩展。
- **题目整理者：** 从题目页导出 JSON，或加载题目集并导出作业 Markdown。
- **答题者：** 粘贴已有答案，或主动向自己配置的 AI 服务请求答案，再选择是否回填。
- **维护者：** 修改实现时维护本文及相关架构、契约和设计文档。

## 功能需求

### FR-01：页面识别与助手面板

扩展应在 Pintia 页面提供助手面板，并在题集概览页及具体题目页识别当前题目集。题目概览页只需读取题集元信息；进入题目页后再读取摘要和题目。用户可在扩展弹窗重新检测题目集、控制助手自动显示，或在页面收起/关闭助手。

**验收条件：** 进入其他 Pintia 页面不会读取当前题目集；进入支持页面后可识别题目并显示提取进度。面板状态和自动显示设置的行为对用户可见。

### FR-02：题目提取与导出

扩展应支持在具体题目页导出当前题目集 JSON，并在用户主动加载列表后从题集概览页或题目页导出一套或多套作业 Markdown。Markdown 按题型组织题目，可选择是否包含平台返回的最近作答；默认包含。题集间隔只控制不同作业导出之间的等待，题目详情间隔控制列表型题目的逐题详情请求。

导出不得推断标准答案。没有可关联评测状态时应标记为未评测/未知；主观题、编程题和 SQL 编程题的作答正文暂不导出。题库 JSON、字段来源及 Markdown 规则见[题库导出契约](./question-export-contract.md)。

**验收条件：** 未点击「加载题目集」前不请求完整题目集列表；题集概览页不读取完整题目；导出的每套作业对应一个 Markdown 文件；没有平台评测信息时不显示猜测的对错。

### FR-03：AI 配置和答案生成

用户可配置兼容 Chat Completions 或 Responses API 的模型服务、提示词、API Key、请求超时及可选的答案复核服务。「生成题型」决定提示词和模型输入包含的题目。只有用户点击「AI 生成答案」后，所选题目数据才发送到已配置的服务。

答案复核默认关闭；启用后会额外请求一次模型服务。复核结果须通过答案契约校验，且题目 ID、题号、题型、数量及顺序须与输入一致。复核失败时应保留第一阶段草稿，并阻止自动回填和保存。

**验收条件：** 未配置有效服务或未选择题目时不能生成；请求期间可查看阶段、耗时和错误；编程题生成前要求选择语言并确认题目详情可用。

### FR-04：答案 JSON 校验和页面回填

用户可以粘贴或编辑答案 JSON，并选择「回填题型」。扩展应在操作前校验 JSON、题集 ID、题目 ID 和受支持题型的答案格式，再按题目 ID 定位页面控件，逐题验证并提供汇总报告。

支持单选、多选、判断、填空、程序填空、编程和 SQL 编程回填。主观题及未知题型不回填，应在报告中说明跳过。具体字段及行为见[答案 JSON 契约](./answer-json-contract.md)和[答案回填设计](./answer-fill-design.md)。

**验收条件：** 格式错误或题集 ID 不匹配时不开始回填；单题失败不隐去原因；题目定位不使用题号、题干或选项文字猜测。

### FR-05：答案写入和保存控制

「生成题型」与「回填题型」互相独立。AI 生成时「自动回填并保存」默认勾选；用户可在请求期间取消，以先查看和修改答案。只有最终答案通过校验且与回填范围有交集时才会自动执行。手动回填单一题型时，关闭保存只修改当前页面；涉及多种可回填题型且未勾选保存时，扩展须先提示，确认后逐类保存，避免切换题型页面时丢失修改。

编程题和 SQL 编程题不自动切换 Pintia 编辑器语言；用户须手动选择与助手一致的语言，并在操作前把光标放到目标编辑器。

**验收条件：** 保存行为由界面明确显示；自动回填失败或复核失败时不得呈现为成功；逐题结果和保存结果可在助手日志中查看。

### FR-06：版本更新提示

扩展打开弹窗时检查 GitHub 最新 Release；结果缓存 6 小时，并允许用户手动重查。更新通过 Release 页面供用户下载和重新加载，不自动覆盖本地扩展目录。

**验收条件：** 版本检查只读取本仓库 Release 元数据；网络或 API 失败时显示可理解的错误，不影响本地题目操作。

## 非功能需求与边界

- **隐私：** AI 配置和密钥保存在 `chrome.storage.local`；不得记录密钥、题目或答案。向非扩展页面提供配置时不得暴露密钥。
- **最小权限：** 只请求当前功能所需的浏览器和主机权限。配置自定义 AI 地址时由浏览器控制对该主机的连接权限。
- **兼容：** 保持 Manifest V3、既有消息、存储和答案/导出字段兼容；变更契约须同步更新文档与调用方。
- **透明：** 页面修改、模型请求、自动保存和失败原因必须对用户清楚可见。
- **安全使用：** 题目与模型答案都视为不可信输入；不得绕过登录、隐藏答案保护或平台评测。
