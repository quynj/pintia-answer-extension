# 产品说明

## 产品定位

Pintia 学习辅助工具是一个运行在用户浏览器中的 Chrome / Edge Manifest V3 扩展。它帮助用户整理当前已打开题集的题目、生成结构化题库文件，并在用户主动操作后调用兼容的 AI 服务生成答案，或将符合约定的答案写入 PTA 页面。

工具不绕过登录或站点权限，不读取隐藏答案。模型生成内容可能不准确，用户应在回填前检查 JSON、答案内容和题型勾选状态。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 题库检测 | 从当前 Pintia 页面已加载的题库 API 中提取题集 ID、题目、题号、题型、选项及原始数据。 |
| 题库导出 | 在页面助手中下载结构化 JSON，支持 API 返回的 JSON 或 Protobuf 数据。 |
| AI 配置 | 从页面助手打开配置页，配置兼容 Chat Completions 或 Responses API 的模型服务、提示词和 API Key。 |
| AI 辅助分析 | 用户配置模型服务后，可提交已勾选题型的题目；可选自动校验、回填并保存。 |
| 网页 AI Prompt | 复制包含题集和所选题型题目的 Prompt，供用户粘贴至其他 AI 页面。 |
| 答案解析与回填 | 在悬浮助手中检查 API 返回的 JSON，或粘贴手工答案；选择要处理的题型后显式启动回填。 |

## 典型使用流程

1. 在 Pintia 登录并进入具体作业或题集页面。
2. 打开扩展并检测题库，然后打开助手面板。也可以直接打开助手，让它读取当前题库。
3. 在助手面板中按需导出题库 JSON，或打开 AI 配置填写模型服务信息。
4. 如需自动操作，在 AI 配置中开启“API 返回后自动回填并保存”；该选项默认关闭。
5. 在助手中勾选题型。此选择同时决定复制 Prompt、API 分析所包含的题目，以及回填时处理的答案类型。
6. 选择一种答案来源：复制 Prompt 到网页 AI，或通过已配置的模型 API 生成答案；也可以直接粘贴答案 JSON。
7. 手动模式下，检查答案后点击“解析并回填”；自动模式下，API 返回后会直接校验答案、回填勾选题型并调用页面保存。
8. 扩展按题型切换 PTA 左侧分类，只用题目 ID 定位题目，注入并验证答案；每个有成功验证答案的题型批次结束后，点击 PTA 页面底部保存按钮。
9. 查看悬浮助手中的总数、成功、失败、跳过数量及逐题失败原因。

点击“解析并回填”或启用自动模式会修改 PTA 页面中的作答状态，并触发当前页面的保存按钮。自动模式跳过人工检查，模型答案不一定正确；用户应先确认当前题集、AI 配置和勾选的题型。保存后的结果受 PTA 当前页面行为和账号权限影响。

## 支持范围

| 标准题型 | 回填支持 | 答案格式 |
| --- | --- | --- |
| `single_choice` | 支持 | 选项标识字符串，例如 `"B"` |
| `multiple_choice` | 支持 | 选项标识数组，例如 `["A", "C"]` |
| `true_false` | 支持 | 布尔值 `true` 或 `false` |
| `fill_blank` | 支持 | 字符串数组，按空位索引排列 |
| `programming` | 不回填 | 标记为跳过 |
| `short_answer` | 不回填 | 标记为跳过 |
| 其他类型 | 不回填 | 标记为跳过 |

未勾选的受支持题型同样不会回填，并在结果中标记为“question type not selected”。

## AI 配置与数据处理

- AI 服务类型、地址、模型、提示词和 API Key 由用户从页面助手打开配置页进行设置。
- 自动回填与保存是可选配置，默认关闭；开启后只对 API 返回的答案生效，并仍经过 JSON 校验和现有回填验证。
- 配置和 API Key 保存于 `chrome.storage.local`。
- 仅当用户主动点击“API 辅助分析”时，所选题型的题目数据才会发送到配置的第三方模型服务。
- 题库提取和答案注入在 Pintia 页面内容脚本中进行；答案文本可由用户检查或编辑。
- AI 答案在回填前必须通过 JSON 解析和字段校验；无效 JSON 或不匹配的题集 ID 会阻止执行。

## 使用边界

- 回填以 `problemId` 精确定位 PTA 题目根容器，不按题干、题号或选项文案进行模糊匹配。
- PTA 页面布局、导航 ID 或控件 ID 变化时，导航或注入可能失败；执行报告会给出失败原因。
- 当前不实现 OCR、编程题和简答题自动回填，也不根据答案文本推断题目位置。
- 浏览器扩展权限、Pintia 登录状态、网络状态和 PTA 页面自身的保存逻辑都会影响运行结果。

安装步骤和弹窗状态说明见项目根目录的 [README](../README.md)。
