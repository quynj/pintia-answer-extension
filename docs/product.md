# 产品说明

## 产品定位

Pintia 学习辅助工具是面向 Chrome 和 Edge 的 Manifest V3 浏览器扩展，可提取当前题集中的题目、生成结构化题库文件，并在用户主动操作后调用兼容的 AI 服务生成答案，或将符合约定的答案写入 PTA 页面。

本工具遵循站点登录和浏览器权限机制，不读取隐藏答案。模型生成内容可能存在错误；回填前应检查 JSON 格式、答案内容及所选题型。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 版本检查 | 打开扩展弹窗时检查 GitHub 仓库最新 Release；结果缓存 6 小时，可手动重新检查。新版本需用户下载并重新加载本地扩展目录。 |
| 题库检测 | 从当前 Pintia 页面已加载的题库 API 中提取题集 ID、题目、题号、题型、选项及原始数据。 |
| 题库导出 | 在页面助手中下载结构化 JSON，支持 API 返回的 JSON 或 Protobuf 数据。 |
| AI 配置 | 从页面助手打开配置页，配置兼容 Chat Completions 或 Responses API 的模型服务、提示词和 API Key。 |
| AI 答案生成 | 用户配置模型服务后，可提交所选题型的题目；可启用答案复核，由模型重新解题并审阅初稿；自动回填仅处理最终答案。 |
| 外部 AI 提示词 | 复制包含题集和所选题型题目的提示词，供用户提交至其他 AI 服务。 |
| 答案校验与回填 | 在页面助手中检查模型返回的 JSON，或粘贴答案；选择处理题型后手动启动回填。 |

## 典型使用流程

1. 在 Pintia 登录并进入具体作业或题集页面；页面会自动检测题目并显示答案助手，同一题集只自动检测一次。助手展开/收起状态会在下次进入题集时恢复。
2. 在扩展弹窗中可重新检测题集以刷新结果，也可切换答案助手的显示/隐藏；弹窗同时检查 GitHub 最新 Release，可手动重新检查并打开发布页。下载新版 ZIP 并解压后，需在扩展管理页加载新版目录；不会自动安装更新。通过弹窗隐藏面板不会清除本次页面状态。点击面板标题栏的「×」关闭时，若 AI 任务正在准备或生成，助手会先提示并在确认后取消任务；若已有答案内容，也会提示关闭后不会保留。收起面板不会影响进行中的任务或答案。
3. 在答案助手中按需导出题库 JSON，或打开 AI 配置页填写模型服务信息。
4. 可在 AI 配置页展开“高级设置”启用答案复核；默认复用主模型，也可单独配置复核模型。自动回填与保存由答案助手面板中的统一开关控制，默认关闭。
5. 在答案助手中选择题型。该选择决定提示词和 AI 请求包含的题目，以及答案回填时处理的题型；若包含编程题，再选择实现语言，扩展会将语言要求加入提示词。
6. 选择答案来源：将提示词提交至其他 AI 服务、使用已配置的模型 API 生成答案，或粘贴答案 JSON。
7. 未启用自动回填时，最终答案会载入页面助手的“答案内容（JSON）”编辑区；检查或修改后，点击“校验并回填/输入”。单一题型只修改页面、不触发保存；如果答案包含多种可回填题型，会在开始前提示，并在确认后逐类保存，以免切换 PTA 题型页面时丢失答案。启用自动回填时，未启用答案复核则在初稿返回后开始校验和回填；启用答案复核则等待复核结果，再校验最终答案、处理所选题型并触发页面保存。复核未完成时，编辑区保留第一阶段草稿，不会自动回填或保存。
8. 普通题型按题型切换 PTA 左侧分类，只用题目 ID 定位题目，注入并验证答案；编程题不自动切换分类，而是按题目 ID 在题目容器内定位代码编辑器，并将代码逐字输入到操作前记录的光标位置。如果页面未提供题目容器，单题答案可回退到页面唯一可见代码编辑器；若答案中包含多道编程题，则按当前 URL 中匹配的题目 ID 只处理当前页题目。需手动将 PTA 编辑器语言切换为助手中选择的语言，并把光标放入对应编辑器；点击助手面板后编辑器无需继续保持焦点。每个有成功验证答案的题型批次结束后，点击 PTA 页面底部保存按钮。
9. 在页面助手中查看题目总数、成功数、失败数、跳过数及逐题失败原因。

点击“校验并回填/输入”会修改 PTA 页面中的作答状态；单一题型手动回填只有助手面板统一开关开启时才触发保存。手动回填多种可回填题型时，为避免切换分类导致未保存答案丢失，会在开始前提示并征求确认，确认后逐类保存。开启该开关也会在 AI 生成最终答案后自动回填并保存。AI 请求和回填范围遵循已勾选题型；全选时覆盖整套题中的可回填题型。编程题按题目 ID 定位编辑器并恢复操作前记录的光标逐字输入；扩展不会切换 PTA 编辑器语言，必须手动与助手中选择的实现语言保持一致。简答题暂不支持页面回填。自动回填不会经过人工确认，模型答案不一定正确；操作前应确认当前题集、AI 配置和所选题型。保存结果受 PTA 页面行为和账号权限影响。

## 支持范围

| 标准题型 | 回填支持 | 答案格式 |
| --- | --- | --- |
| `single_choice` | 支持 | 选项标识字符串，例如 `"B"` |
| `multiple_choice` | 支持 | 选项标识数组，例如 `["A", "C"]` |
| `true_false` | 支持 | 布尔值 `true` 或 `false` |
| `fill_blank` | 支持 | 字符串数组，按空位索引排列 |
| `programming` | 逐字输入 | 非空源代码字符串；按题目 ID 定位对应题目容器中的代码编辑器，并输入到操作前记录的光标位置 |
| `short_answer` | 不回填 | 标记为跳过 |
| 其他类型 | 不回填 | 标记为跳过 |

未勾选的受支持题型同样不会回填，并在结果中标记为“question type not selected”。

## AI 配置与数据处理

- AI 服务类型、地址、模型、提示词和 API Key 由用户从页面助手打开配置页进行设置。
- 自动回填与保存由答案助手面板统一控制，默认关闭；启用后仅处理最终模型答案，并执行 JSON 校验和现有回填验证。手动回填单一题型时，关闭开关只修改页面；手动回填多个可回填题型时，为避免题型页面切换丢失答案，会在开始前征求确认并逐类保存。答案复核未完成时会阻止自动回填和保存。
- 答案复核默认关闭，默认复用主 AI 配置；用户可选独立配置复核模型。复核会额外向所配置的模型服务发送题目数据和第一阶段答案，有助于发现错误，但不保证答案正确。
- 配置和 API Key 保存于 `chrome.storage.local`。
- 仅当用户主动点击“AI 生成答案”时，所选题型的题目数据才会发送到配置的模型服务。
- 题库提取和答案注入在 Pintia 页面内容脚本中进行；答案文本可由用户检查或编辑。
- 未启用自动回填时，模型返回的答案会载入页面助手答案编辑区，供用户检查或修改；手动回填单一题型仅修改页面，不保存。若答案涉及多个可回填题型，则确认后逐类保存。答案在回填前必须通过 JSON 解析和字段校验。无效 JSON 或不匹配的题集 ID 会阻止执行。
- AI 诊断日志开关位于答案助手面板；阶段、耗时和错误类别仅显示在当前页面会话中，不记录题目、答案或密钥。
- 单次模型请求默认最多等待 60 秒，可在高级设置中调整为 10–300 秒。初稿和答案复核分别计时；启用复核时，总等待时间可能接近单次上限的两倍。

## 使用边界

- 回填以 `problemId` 精确定位 PTA 题目根容器，不按题干、题号或选项文案进行模糊匹配。
- PTA 页面布局、导航 ID 或控件 ID 变化时，导航或注入可能失败；执行报告会给出失败原因。
- 当前不实现 OCR、简答题自动回填，也不根据答案文本推断题目位置；编程题按题目 ID 定位编辑器，使用操作前记录的光标逐字输入。
- 浏览器扩展权限、Pintia 登录状态、网络状态和 PTA 页面自身的保存逻辑都会影响运行结果。
- 版本检查只向 `api.github.com` 请求此仓库的最新 Release 元数据，不会上传题目、答案或 AI 配置；网络不可用时可在弹窗中重试。

安装与快速上手见项目根目录的 [README](../README.md)；答案 JSON 和题库导出字段分别见[答案 JSON 契约](./answer-json-contract.md)和[题库导出格式](./question-export-format.md)。
