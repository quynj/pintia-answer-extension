# 产品说明

## 产品定位

Pintia 学习辅助工具是面向 Chrome 和 Edge 的 Manifest V3 浏览器扩展，可提取当前题集中的题目、生成结构化题库文件，并在用户主动操作后调用兼容的 AI 服务生成答案，或将符合约定的答案写入 PTA 页面。

本工具遵循站点登录和浏览器权限机制，不读取隐藏答案。模型生成内容可能存在错误；回填前应检查 JSON 格式、答案内容及所选题型。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 版本检查 | 打开扩展弹窗时检查 GitHub 仓库最新 Release；结果缓存 6 小时，可手动重新检查。新版本需用户下载并重新加载本地扩展目录。 |
| 题库检测 | 从当前 Pintia 页面已加载的题库 API 中提取题集 ID、题目、题号、题型、选项及原始数据。 |
| 题库导出 | 在页面助手中下载结构化 JSON，支持 API 返回的 JSON 或 Protobuf 数据。 |
| 导出Markdown | 从题目集列表选择一套或多套题目集，按每套题目集的题型摘要仅读取实际存在的题型和题目，并为每套题目集生成 Markdown 文件；可选择是否包含平台返回的最近作答，默认包含。主观题、编程题及 SQL 编程题的作答内容暂不支持导出。选择多套题目集时可设置仅作用于题集之间的间隔；列表型题目可设置逐题详情请求间隔，覆盖自动识别、JSON 题库导出触发的提取及 Markdown 导出。平台未明确返回逐题评测结果时标记为未知，不推断标准答案。 |
| AI 配置 | 从页面助手打开配置页，配置兼容 Chat Completions 或 Responses API 的模型服务、提示词和 API Key。 |
| AI 答案生成 | 用户配置模型服务后，可提交所选题型的题目；可启用答案复核，由模型重新解题并审阅初稿；自动回填仅处理最终答案。 |
| 外部 AI 提示词 | 复制包含题集和所选题型题目的提示词，供用户提交至其他 AI 服务。 |
| 答案校验与回填 | 在页面助手中检查模型返回的 JSON，或粘贴答案；选择处理题型后手动启动回填。 |

## 典型使用流程

1. 在 Pintia 登录并进入任意 Pintia 页面；默认会自动显示答案助手。题集概览页或题目页会自动识别当前题目集，同一题集只自动检测一次；提取期间面板显示当前题型及列表型题目的详情读取进度。助手展开/收起状态会在下次进入题集时恢复。
2. 在扩展弹窗中可重新检测题集以刷新结果，也可点击「显示或隐藏助手面板」按全局自动显示设置切换：启用时点击会关闭自动显示并隐藏各页面面板；关闭时点击会显示当前页面板并重新启用自动显示，之后进入 Pintia 页面会自动显示。页面内「×」会关闭并清空当前页面板，但不改变全局设置；若 AI 任务正在进行或答案框已有内容，会先提示确认，确认后取消任务并清除内容，取消确认则保持面板不变。因此弹窗仍根据全局设置切换，不依赖当前面板是否存在。收起面板不会影响进行中的任务或答案。弹窗同时检查 GitHub 最新 Release，可手动重新检查并打开发布页。下载新版 ZIP 并解压后，需在扩展管理页加载新版目录；不会自动安装更新。
3. 登录后进入任意 Pintia 页面，默认自动显示助手；仅在题集概览页或题目页自动识别并显示当前题目集，其他页面不会识别当前题集，离开题集概览页或题目页时也会清除临时当前项且不再请求当前题集信息。题目读取期间会显示当前题型和列表型题目的逐题详情进度。不会自动获取完整题目集列表。点击“加载题目集”后才会加载全部可访问的题目集；此时会保留并选中当前题目集，也可选择其他题目集。选择一个或多个题目集后点击“导出 Markdown”，每套题目集各下载一个 Markdown 文件。重复加载不会重复显示题目集，并会保留已有选择。可取消“包含作答内容”以隐藏最近作答；该选项默认开启，且不提供标准答案。普通题型的作答仅在平台返回可关联的最近提交记录时导出；主观题、编程题及 SQL 编程题的作答内容暂不支持导出，题目正文和可识别的评测标记仍会保留。选择多套题目集时，“题集间隔”默认 300 毫秒，仅在一套 Markdown 导出完成到下一套开始前等待，可设置为 0–10000 毫秒；“题目详情间隔”默认 1000 毫秒，仅控制列表型题目（普通编程、SQL 编程、程序填空、主观题）的逐题详情请求，自动识别、JSON 题库导出触发的提取和 Markdown 导出均使用，可设置为 0–10000 毫秒。导出只读取题型摘要中实际存在的题型，图片继续使用 Pintia 在线图片地址。错题标记依赖平台返回的逐题评测信息；无评测信息时会显示“未评测/未知”，不会推测标准答案。AI 答题、回填及当前题库 JSON 导出仍要求进入具体作业题目页。
4. 可在 AI 配置页展开“高级设置”启用答案复核；默认复用主模型，也可单独配置复核模型。自动回填与保存由答案助手面板中的统一开关控制，默认关闭。
5. 在答案助手中选择题型。该选择决定提示词和 AI 请求包含的题目，以及答案回填时处理的题型；若包含 `PROGRAMMING` 或 `SQL_PROGRAMMING`，再选择实现语言，扩展会将语言要求加入提示词。
6. 选择答案来源：将提示词提交至其他 AI 服务、使用已配置的模型 API 生成答案，或粘贴答案 JSON。
7. 未启用自动回填时，最终答案会载入页面助手的“答案内容（JSON）”编辑区；检查或修改后，点击“校验并回填/输入”。单一题型只修改页面、不触发保存；如果答案包含多种可回填题型，会在开始前提示，并在确认后逐类保存，以免切换 PTA 题型页面时丢失答案。启用自动回填时，未启用答案复核则在初稿返回后开始校验和回填；启用答案复核则等待复核结果，再校验最终答案、处理所选题型并触发页面保存。复核未完成时，编辑区保留第一阶段草稿，不会自动回填或保存。
8. 普通题型按题型切换 PTA 左侧分类，只用题目 ID 定位题目，注入并验证答案；编程题不自动切换分类，而是按题目 ID 在题目容器内定位代码编辑器，并将代码逐字输入到操作前记录的光标位置。如果页面未提供题目容器，单题答案可回退到页面唯一可见代码编辑器；若答案中包含多道编程题，则按当前 URL 中匹配的题目 ID 只处理当前页题目。需手动将 PTA 编辑器语言切换为助手中选择的语言，并把光标放入对应编辑器；点击助手面板后编辑器无需继续保持焦点。每个有成功验证答案的题型批次结束后，点击 PTA 页面底部保存按钮。
9. 在页面助手中查看题目总数、成功数、失败数、跳过数及逐题失败原因。

点击“校验并回填/输入”会修改 PTA 页面中的作答状态；单一题型手动回填只有助手面板统一开关开启时才触发保存。手动回填多种可回填题型时，为避免切换分类导致未保存答案丢失，会在开始前提示并征求确认，确认后逐类保存。开启该开关也会在 AI 生成最终答案后自动回填并保存。AI 请求和回填范围遵循已勾选题型；全选时覆盖整套题中的可回填题型。编程题和 SQL 编程题按题目 ID 定位编辑器并恢复操作前记录的光标逐字输入；扩展不会切换 PTA 编辑器语言，必须手动与助手中选择的实现语言保持一致。主观题暂不支持页面回填。自动回填不会经过人工确认，模型答案不一定正确；操作前应确认当前题集、AI 配置和所选题型。保存结果受 PTA 页面行为和账号权限影响。

## 支持范围

| Pintia 题型 (`type`) | 助手面板名称 | 答案 JSON `type` | 回填支持 |
| --- | --- | --- | --- |
| `MULTIPLE_CHOICE` | 单选题 | `MULTIPLE_CHOICE` | 支持 |
| `MULTIPLE_CHOICE_MORE_THAN_ONE_ANSWER` | 多选题 | `MULTIPLE_CHOICE_MORE_THAN_ONE_ANSWER` | 支持 |
| `TRUE_OR_FALSE` | 判断题 | `TRUE_OR_FALSE` | 支持 |
| `FILL_IN_THE_BLANK` | 填空题 | `FILL_IN_THE_BLANK` | 支持 |
| `FILL_IN_THE_BLANK_FOR_PROGRAMMING` | 程序填空题 | `FILL_IN_THE_BLANK_FOR_PROGRAMMING` | 按代码块中填空框的 DOM 顺序回填并逐空验证 |
| `PROGRAMMING` | 编程题 | `PROGRAMMING` | 逐字输入非空源代码 |
| `SQL_PROGRAMMING` | SQL编程题 | `SQL_PROGRAMMING` | 按编程题方式逐字输入非空代码 |
| `SUBJECTIVE` | 主观题 | `SUBJECTIVE` | 不回填，标记为跳过 |
| 其他类型 | 显示 Pintia 原始类型名 | 保持接口原始值 | 不回填，标记为跳过 |

答案、提示词和题目导出中的 `type` 都保留 Pintia 原始题型值，不再映射为扩展自定义类型。为兼容别名，平台若返回 `SINGLE_CHOICE` 会规范为 Pintia 使用的 `MULTIPLE_CHOICE`，`TRUE_FALSE` 会规范为 `TRUE_OR_FALSE`；其他类型原样保留。`PROGRAMMING`、`SQL_PROGRAMMING` 和 `SUBJECTIVE` 在面板中分别显示为编程题、SQL编程题和主观题；两种编程题使用相同的题目列表/详情请求、语言设置和编辑器输入流程。题目导出中的 `apiData` 保留接口原始数据。

未勾选的受支持题型同样不会回填，并在结果中标记为“question type not selected”。

## AI 配置与数据处理

- AI 服务类型、地址、模型、提示词和 API Key 由用户从页面助手打开配置页进行设置。
- 自动回填与保存由答案助手面板统一控制，默认关闭；启用后仅处理最终模型答案，并执行 JSON 校验和现有回填验证。手动回填单一题型时，关闭开关只修改页面；手动回填多个可回填题型时，为避免题型页面切换丢失答案，会在开始前征求确认并逐类保存。答案复核未完成时会阻止自动回填和保存。
- 答案复核默认关闭，默认复用主 AI 配置；用户可选独立配置复核模型。复核会额外向所配置的模型服务发送题目数据和第一阶段答案，有助于发现错误，但不保证答案正确。
- 配置和 API Key 保存于 `chrome.storage.local`。
- 仅当用户主动点击“AI 生成答案”时，所选题型的题目数据才会发送到配置的模型服务。
- 题库提取和答案注入在 Pintia 页面内容脚本中进行；答案文本可由用户检查或编辑。
- 未启用自动回填时，模型返回的答案会载入页面助手答案编辑区，供用户检查或修改；手动回填单一题型仅修改页面，不保存。若答案涉及多个可回填题型，则确认后逐类保存。答案在回填前必须通过 JSON 解析和字段校验。无效 JSON 或不匹配的题集 ID 会阻止执行。
- AI 诊断日志开关位于答案助手面板；阶段、耗时和错误类别仅显示在当前页面会话中，不记录题目、答案或密钥。
- 单次模型请求默认最多等待 60 秒，可在高级设置中调整为 10–300 秒。初稿和答案复核分别计时；启用复核时，总等待时间可能接近单次上限的两倍。

## 使用边界

- 回填以 `problemId` 精确定位 PTA 题目根容器，不按题干、题号或选项文案进行模糊匹配。
- PTA 页面布局、导航 ID 或控件 ID 变化时，导航或注入可能失败；执行报告会给出失败原因。
- 当前不实现 OCR、主观题页面回填，也不根据答案文本推断题目位置。程序填空题按题目 ID 定位题目容器，在代码块中依 DOM 顺序定位填空输入框；控件数量与答案项数不一致时会明确失败，不尝试猜测定位。编程题与 SQL 编程题按题目 ID 定位编辑器，使用操作前记录的光标逐字输入。
- 浏览器扩展权限、Pintia 登录状态、网络状态和 PTA 页面自身的保存逻辑都会影响运行结果。
- 版本检查只向 `api.github.com` 请求此仓库的最新 Release 元数据，不会上传题目、答案或 AI 配置；网络不可用时可在弹窗中重试。

安装与快速上手见项目根目录的 [README](../README.md)；答案 JSON 和题库导出字段分别见[答案 JSON 契约](./answer-json-contract.md)和[题库导出格式](./question-export-format.md)。
